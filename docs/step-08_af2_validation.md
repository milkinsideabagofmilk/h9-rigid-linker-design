# Step 08 — AF2-multimer back-prediction validation (16/20 pass)

Purpose: run AlphaFold2-multimer structure prediction on the 20 C3-tied sequences
from step 07 to verify that the designed sequences spontaneously fold into the target
C3 trimer conformation. **This is the final gate of the pipeline.**

**Current results are based on the sequences from the relaxed new top 10 (rerun
2026-09-20)**; the old unrelaxed-top-10 products are archived in
`deprecated_unrelaxed_top10/`, do not use.

## Layout

- `input/ck_xt_24_mpnn_c3_tied_20.fasta` — 20 entries; each is three identical
  sequences (193 aa; the MPNN output already includes a C-terminal His6) joined with
  `:` into a trimer (579 aa total). Generated by `scripts/build_af2_fasta.py` from
  the step-07 `seqs/*.fa`.
- `scripts/build_af2_fasta.py` — FASTA construction (verifies three-chain identity,
  193 aa, His6 tail).
- `scripts/summarize_af2_results.py` — aggregates the results CSV (metric
  definitions below).
- `scripts/structural_checks.py` — structural checks: linker helix (phi/psi,
  CA(i)-(i+4)), bend, C3 symmetry, clash, core-RMSD to the designed backbone
  (alignment reference = linker+scaffold 47-193).
- `scripts/final_candidate_table.py` — merges AF2 + structural checks + Rosetta
  rescore energies → final candidate table.
- `output/`
  - `results_conservative/` — **official results (use only this set)**: per-design
    a3m, coverage/pae/plddt PNGs, scores JSON, PAE JSON, `unrelaxed_rank_001` PDB, MSA
    cache, done marker, `config.json`, `log.txt`
  - `results_conservative_summary.csv` — 20-row summary (plddt_mean, linker /
    linker_flank pLDDT, pTM, ipTM, PAE, inter-chain PAE), sorted by ipTM descending
  - `structural_checks.csv` — 20 structural check rows (PASS thresholds in the script
    header comments)
  - `rosetta_rescore/` — FastRelax + scoring of the 16 AF2-passing structures
    (reusing the step-06 protocol and script),
    `ck_xt_24_rosetta_linker_scores_relaxed.csv`
  - `final_candidates.csv` — **final candidate table (10)**: ipTM ≥ 0.65 and
    struct_pass
  - `af2_rerun_console.log` — rerun console log (one level up from this directory)
- `deprecated_unrelaxed_top10/` — AF2 inputs and results of the old unrelaxed top 10
  (before 2026-09-18), do not use

## How to run / key parameters

```bash
XLA_FLAGS="--xla_gpu_autotune_level=1" <colabfold-venv>/bin/colabfold_batch \
  input/ck_xt_24_mpnn_c3_tied_20.fasta output/results_conservative \
  --num-models 1 --num-recycle 3 --model-type alphafold2_multimer_v3 \
  --rank multimer --max-seq 64 --max-extra-seq 128 \
  --pair-mode unpaired_paired --random-seed 0 \
  --disable-unified-memory \
  --host-url https://api.colabfold.com
python3 scripts/summarize_af2_results.py
```

ColabFold 1.6.1, local RTX 5090, MSA via the public server (mmseqs2_uniref_env). By
default existing results are kept (naturally resumable; queries with an existing a3m
skip MSA).

**Critical WSL2 lesson (2026-09-20)**: this machine is WSL2, and XLA unified memory
by default spills buffers to host memory — it once tried to allocate 136 GB of pinned
host memory (over the 70 GB VM limit), the process was OOM-killed with no traceback;
Windows Task Manager shows all WSL CUDA usage as "shared GPU memory", per-process
memory shows [N/A] in `nvidia-smi` under WSL, and the only trustworthy metric is the
memory.used total. **Always pass `--disable-unified-memory`**; lowering
`xla_gpu_autotune_level` shortens compilation. When debugging, do not pipe through
`| tail` (it masks the real exit code).

## Results (2026-09-20, sequences from the relaxed new top 10)

- **16/20 pass** (ipTM ≥ 0.65), pLDDT_mean 72–84. By backbone: 7 backbones pass with
  both sequences (01_rank_003_0073_0, 02_rank_007_0107_4, 03_rank_004_0109_5,
  05_rank_016_0075_3, 06_rank_010_0074_8, 08_rank_003_0073_6, 10_rank_011_0110_1),
  2 pass with one sequence (04, 07), 1 fails both (09_rank_003_0073_8).
- Top three: `05_rank_016_sample_0075_3_sample1` (ipTM=0.72, pLDDT=81.7, linker
  pLDDT=74.6), `06_rank_010_sample_0074_8_sample1` (0.72, 83.6),
  `03_rank_004_sample_0109_5_sample1` (0.71, 83.8).
- Note: `03_rank_004_sample_0109_5` failed both sequences in the previous round
  (unrelaxed backbones + old sequences, ipTM 0.17/0.20); this round with relaxed
  backbones + new sequences it passes both (0.71/0.68) — a direct payoff of fixing
  the pipeline.
- Some passing designs have low linker pLDDT (e.g. `02_..._sample1` at 35.8): trimer
  assembly is credible but the linker conformation is uncertain — watch this in
  structural checks.

## Structural checks & Rosetta rescore (2026-09-20, completed)

- **Structural checks** (`structural_checks.py`): **10 of the 16** AF2-passing designs
  pass. Internal metrics are all excellent (linker helix 0.88–1.00, bend ≤ 25°,
  scaffold-to-design RMSD ~0.3 Å, linker self-alignment RMSD ~0.7 Å); eliminations
  are mainly trimer asymmetry (sym_rmsd 2.2–10.6) or bend.
- **Key insight — the HA-fragment artifact**: the construct contains only the HA
  480-525 fragment (46 aa, without the full HA trimer context); AF2 predicts it with
  pLDDT ≈ 47, deviating ~12 Å from native (self-alignment RMSD), and it weakly drags
  the linker terminus (a helical-phase difference with a ~3.6-residue swing period).
  The hard fidelity metric of the structural checks is therefore **core_rmsd ≤ 2.5**
  (linker+scaffold alignment); linker terminal displacement is reported for
  reference only, with no threshold. The perfect fidelity of the linker/scaffold
  themselves shows the design holds in the trustworthy region.
- **Rosetta rescore** (reusing the step-06 relax protocol on the 16 AF2-passing
  structures): all PASS, post-relax linker+flank energy −162.8 ~ −224.1 (note: these
  are energies **with real designed sequences**, not comparable to the step-06
  placeholder-sequence energies). Best: `05_..._sample1` and `03_..._sample1`
  (both ≈ −224).
- **Final candidates = ipTM ≥ 0.65 and struct_pass, 10 total**
  (`final_candidates.csv`), covering 9 backbones (only 09 failed entirely). Best
  overall: `05_rank_016_sample_0075_3_sample1` (ipTM 0.72 + flankE −224.1) and
  `03_rank_004_sample_0109_5_sample1` (0.71, −224.0); best structural fidelity:
  `04_rank_003_sample_0073_1_sample1` (coreRMSD 0.75).

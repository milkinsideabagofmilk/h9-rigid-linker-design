# Step 07 — ProteinMPNN linker sequence design (C3-tied, 10 × 2 = 20 sequences)

Purpose: run **linker-only** sequence design on the **new post-FastRelax top-10**
backbones from step 06 — only the 20 aa linker is designed, all other residues are
fixed; corresponding positions on the three chains are tied, forcing identical linker
sequences across the C3 trimer. Produces 20 sequences for step 08 AF2 validation.

**Current results are based on the relaxed new top 10 (rerun 2026-09-20)**; the old
unrelaxed-top-10 products are archived in `deprecated_unrelaxed_top10/`, do not use.

## Layout

- `input/top10_relaxed_pdbs/` — the **post-relax** PDBs of the new top 10 (`01_`–`10_`
  prefixes, from `06_rosetta_scoring/output_relaxed/jobs/`; post-relax flank energy
  −53.6 ~ −44.7). PDBs use Rosetta continuous numbering (A:1-193, B:194-386,
  C:387-579); ProteinMPNN parses them per chain, and the linker is 47-66 on every chain.
- `input/*.jsonl` — design constraints (regenerated by the ProteinMPNN helper
  scripts for the current inputs; only this set is valid):
  - `parsed_pdbs.jsonl` — `parse_multiple_chains.py`
  - `assigned_pdbs_ABC.jsonl` — `assign_fixed_chains.py --chain_list "A B C"`,
    `[["A","B","C"],[]]`
  - `fixed_linker_only_ABC.jsonl` — per chain, residues 1-46 and 67-193 fixed
    (173 residues), only 47-66 designable; note the helper's `--position_list`
    accepts only space-separated explicit residue numbers, so ranges must be expanded
  - `tied_c3_linkers_ABC.jsonl` — 20 groups `{A:[n],B:[n],C:[n]}, n=47..66`
- `scripts/summarize_mpnn_linkers.py` — aggregates `seqs/*.fa` into a CSV and
  verifies the three-chain linker identity.
- `output/`
  - `mpnn_out_c3_tied/seqs/*.fa` — 10 FASTA files (native sequence + 2 designed
    sequences per backbone)
  - `mpnn_out_c3_tied/scores/*.npz` — MPNN score per sequence
  - `mpnn_linker_sequences.csv` — 20-sequence summary (score 0.381–0.496, global_score
    1.16–1.21; three-chain linker identity verified, C3 symmetry checked)
- `deprecated_unrelaxed_top10/` — old unrelaxed-top-10 inputs and outputs (products
  before 2026-09-18), do not use

## How to run / key parameters

```bash
python3 <ProteinMPNN-install>/protein_mpnn_run.py \
  --jsonl_path input/parsed_pdbs.jsonl \
  --chain_id_jsonl input/assigned_pdbs_ABC.jsonl \
  --fixed_positions_jsonl input/fixed_linker_only_ABC.jsonl \
  --tied_positions_jsonl input/tied_c3_linkers_ABC.jsonl \
  --out_folder output/mpnn_out_c3_tied \
  --num_seq_per_target 2 \
  --sampling_temp 0.1 \
  --seed 37 \
  --batch_size 1 \
  --save_score 1
python3 scripts/summarize_mpnn_linkers.py
```

Model weights `v_48_020`, no amino-acid-composition bias; parameters identical to the
old version (only the input backbones changed to the relaxed new top 10). ≈ 1.5 s per
backbone on GPU.

**Numbering trap (a real historical error)**: Rosetta/RFdiffusion use pose continuous
numbering (linker = A:47-66, B:240-259, C:433-452), while ProteinMPNN uses
**within-chain** numbering; every chain is 193 aa and its linker is 47-66. The
constraint JSONL files must use within-chain numbering.

## Result characteristics

Sequences show typical rigid-helix character (rich in E/K/A/L, mostly
`KLEENE…AALE…GG`-type repeats), similar to EAAAK-class low-immunogenicity linkers.

## Completion criteria

All 20 designed sequences have identical linkers across the three chains
(`summarize_mpnn_linkers.py` verifies and reports this); the CSV contains the full
10 backbone × 2 sequence grid. Step 08 must use the current
`mpnn_linker_sequences.csv` in this directory.
